## Project Steps

### 1. Load the Dataset
The dataset is imported into Python using Pandas and inspected to understand its structure, data types, and overall quality.

### 2. Exploratory Data Analysis (EDA)
EDA is performed to identify:
- Dataset shape and structure
- Missing values and duplicate records
- Statistical distributions and outliers
- Relationships between variables
- Key trends and patterns

### 3. Data Cleaning
The raw dataset is prepared for analysis by:
- Handling missing values
- Removing duplicates
- Correcting data types
- Standardizing column values
- Treating outliers where appropriate

### 4. SQL Analysis
The cleaned data is loaded into PostgreSQL/MySQL for deeper analysis using:
- Filtering and aggregation
- `GROUP BY` and `ORDER BY`
- Joins across tables
- Subqueries and CTEs
- Window functions for ranking and trend analysis

### 5. Power BI Dashboard
The analyzed data is connected to Power BI to build an interactive dashboard featuring:
- Key Performance Indicators (KPIs)
- Trend analysis over time
- Category-level comparisons
- Interactive filters and slicers
- Visual summaries for quick decision-making

### 6. Report
A detailed report documents:
- The business problem
- Data preparation process
- EDA findings
- SQL analysis and results
- Dashboard insights
- Key conclusions and recommendations

### 7. Presentation
A concise, professional presentation is created using **Gamma** to communicate the project's methodology, findings, and business recommendations to stakeholders.

## How to Run

### 1. Clone the Repository
```bash
git clone <repository-url>
cd data-analytics-project
```

### 2. Install Python Dependencies
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Run the Python Analysis
```bash
jupyter notebook
```
Open and run `notebooks/eda_and_cleaning.ipynb` to load, explore, and clean the dataset.

### 4. Run SQL Queries
Import the cleaned dataset into PostgreSQL or MySQL, configure your database connection, and execute the scripts in the `sql/` folder.

### 5. Open the Power BI Dashboard
Open `powerbi/dashboard.pbix` in Power BI Desktop and refresh the data connection if required.

### 6. Review the Report and Presentation
The final report and Gamma-generated presentation are available in the `report/` and `presentation/` folders.
